# 계정 복구 및 동의 설정

## 회원가입 필수 동의

회원가입 요청은 서비스 이용약관과 개인정보 수집·이용 동의가 모두 `true`일 때만 처리됩니다.
서버는 체크 여부를 다시 검증하고 계정에 동의 시각과 약관 버전을 저장합니다.

현재 수집 항목은 이름, 이메일, 암호화된 비밀번호, 서비스 이용 기록, 업로드 계약서,
분석 결과 및 AI 상담 이력입니다. 회원 탈퇴 시 계정과 관련 데이터가 삭제되며,
관계 법령에 따라 별도 보존이 필요한 정보가 생기면 해당 정책과 저장 구조를 함께 갱신해야 합니다.

## 아이디 및 비밀번호 찾기

- 로그인 아이디는 이메일입니다.
- 아이디 찾기는 이름과 이메일이 모두 일치할 때만 가입 이메일로 안내합니다.
- 비밀번호 찾기는 가입 이메일로 30분 동안 유효한 일회용 링크를 전송합니다.
- 계정 존재 여부 추측을 막기 위해 존재하는 이메일과 존재하지 않는 이메일의 API 응답은 같습니다.
- 비밀번호 재설정 토큰 원문은 DB에 저장하지 않고 SHA-256 해시만 저장합니다.

## SMTP 환경변수

로컬에서는 MailHog 같은 SMTP 테스트 서버를 `localhost:1025`에 실행할 수 있습니다.
배포 환경에서는 다음 값을 실제 메일 서비스에 맞게 설정해야 합니다.

```text
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=...
MAIL_PASSWORD=...
MAIL_SMTP_AUTH=true
MAIL_STARTTLS=true
MAIL_FROM=no-reply@example.com
FRONTEND_URL=https://서비스-도메인
```

SMTP 발송 실패는 계정 존재 여부를 노출하지 않기 위해 동일한 API 응답을 반환하고,
실패 원인은 백엔드 로그에 기록합니다. 배포 전 실제 메일 수신과 재설정 링크의
`FRONTEND_URL`을 반드시 확인해야 합니다.
